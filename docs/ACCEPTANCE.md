# Critères d'acceptation

Cocher uniquement après vérification réelle. Indiquer le navigateur et l'appareil utilisés.

- [ ] `main` contient l'application et les métadonnées (README, licence MIT, gitignore).
- [ ] GitHub Pages est actif et l'URL retourne le site attendu.
- [ ] Aucun asset n'est en 404, manifest chargé, pas d'erreur JS bloquante.
- [ ] Les sept fiches de Noël apparaissent à la première visite.
- [ ] Création d'un projet et d'une recette hors Noël.
- [ ] Création de deux essais V1/V2 distincts et consultation de l'historique.
- [ ] Les observations et notes restent après rafraîchissement.
- [ ] Export JSON, réimport du fichier et export Markdown vérifiés.
- [ ] Import invalide géré sans destruction des données existantes.
- [ ] Interface utilisable sur écran Android ou émulation mobile.
- [ ] Dictée testée sur navigateur compatible, OU limite clairement documentée.
- [ ] Site utilisable hors ligne après premier chargement (dans les limites annoncées).
- [ ] Mise à jour du site testée sans blocage par l'ancien cache.
- [ ] Aucune donnée personnelle ni clé API commitées.

## À signaler explicitement
- Test Android réel vs émulation ; HTTPS et permissions micro.
- Sauvegarde uniquement locale : pas de synchronisation.
- Fonctionnalités non encore implémentées et risques connus.
